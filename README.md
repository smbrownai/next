## Deployment
This site is designed to be hosted via GitHub Pages.

To enable GitHub Pages:
1. Go to **Settings** in this repository
2. Select **Pages** from the sidebar
3. Under **Source**, choose **Deploy from a branch**
4. Select `main` and `/ (root)`, then click **Save**

Your site will be live at `https://yourusername.github.io/next/` — or at your custom domain if configured.

### Custom Domain (shawnnext.ai)
To point your custom domain to GitHub Pages:

1. Add a `CNAME` file to this repo containing `shawnnext.ai`
2. In your domain registrar's DNS settings, add the following `A` records pointing to GitHub's IPs:
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```
3. In **Settings → Pages**, enter `shawnnext.ai` under **Custom domain**
